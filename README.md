README — Reproducing the Figures

Overview

This repository contains all code and processed data required to reproduce the analyses and figures presented in the manuscript:

“RHOG modulates CAR-T activation trajectories without inducing new transcriptional states.”

The analysis is based on publicly available RNA-seq data generated by the CELLFIE CRISPR screening platform (Datlinger et al., 2025). No raw sequencing data are redistributed here.

	•	numpy
	•	pandas
	•	scipy
	•	scikit-learn
	•	statsmodels
	•	matplotlib
	•	seaborn
	•	umap-learn

All analyses were executed in Jupyter notebooks. Exact package versions are documented in the environment file (if present) or can be inferred from the notebooks.

⸻

Data preprocessing

Processed expression matrices were generated from the original published dataset by:
	1.	Normalizing raw gene counts to log counts per million (logCPM)
	2.	Mapping ENSEMBL gene IDs to gene symbols
	3.	Collapsing duplicated gene symbols by mean expression
	4.	Filtering lowly expressed genes

The resulting symbol-level expression matrices are stored in data/processed/ and used consistently across all analyses.

Reproducing figures

Each main figure corresponds to a dedicated notebook and figure directory.

Figure 1 — Computational framework
	•	Notebook: notebooks/fig1_framework.ipynb
	•	Outputs: figures/fig1_framework/

Figure 2 — CAR-T activation trajectories
	•	Notebook: notebooks/fig2_activation_trajectories.ipynb
	•	Outputs: figures/fig2_activation_trajectories/

Figure 3 — Time-driven gene and pathway programs
	•	Notebook: notebooks/fig3_DE_pathways.ipynb
	•	Outputs: figures/fig3_DE_pathways/

Figure 4 — RHOG-associated trajectory bias
	•	Notebook: notebooks/fig4_RHOG_specific.ipynb
	•	Outputs: figures/fig4_RHOG_specific/

Running each notebook from top to bottom will regenerate the corresponding figure panels (.png) and captions.

Notes on scope and reuse
	•	This repository focuses on analytical interpretation of transcriptional trajectories.
	•	It does not reproduce wet-lab experiments, CRISPR screening execution, or in vivo assays.
	•	All biological conclusions are contextualized relative to the original publication.
