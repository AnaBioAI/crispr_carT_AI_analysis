# Archive ("just in case")

This folder stores intermediate/duplicate artifacts that are NOT part of the final manuscript figure set,
but are retained for safety until the project is finalized.

- results_old/: old/duplicate plots and intermediate outputs
- figures_old/: deprecated figure folder variants (e.g., older Fig4 layouts)
- notebooks_old/: notebook-local figures or legacy notebook artifacts
- root_misc/: stray files that shouldn't live at repo root
